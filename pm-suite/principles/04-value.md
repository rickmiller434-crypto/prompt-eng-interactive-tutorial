# Principle 4 — Value

> Focus on value.

## Intent

Value is the ultimate indicator of project success. Outputs (deliverables) are not the same as outcomes (value realized). The project should be continually reassessed against the value it is meant to deliver.

## What it means in practice

- Value is defined up front and made measurable (a benefits register or value hypothesis), not left as marketing copy.
- Trade-offs (scope, time, cost, quality) are made by reference to value, not by reference to "what we said in the plan."
- Benefits realization continues after the project closes.

## Agent behaviors

- `pm-lead` requires a **Business Case / Value Statement** before any planning artifact is produced.
- `pm-delivery` and `pm-measurement` link every delivered increment back to the value statement.
- Change requests must declare expected value impact, not just scope/time/cost impact.

## Audit checks

- [ ] Business case / value statement exists with measurable benefits.
- [ ] Benefits register identifies owner, measure, baseline, target, and realization timeframe per benefit.
- [ ] Status reports include benefits-realization progress, not only output progress.
- [ ] Change requests record value impact.
