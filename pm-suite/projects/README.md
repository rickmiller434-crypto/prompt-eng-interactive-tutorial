# Projects

Per-project working artifacts go here, one directory per project:

```
projects/
  acme-onboarding-revamp/
    tailoring.md
    charter.md
    stakeholder-register.md
    risk-register.md
    status-reports/
    decisions/
    ...
```

In real use you may want to `.gitignore` this directory (or specific subdirectories) if artifacts contain sensitive info; for now it is tracked so the example project (Phase 5) can live here.
