# Templates

Artifact templates organized by process group. Each template will ship in **predictive** and **adaptive** variants where the difference matters; hybrid projects pull from both as the Tailoring Record dictates.

Templates land in Phases 3–5. This README enumerates the planned set so you can see the shape.

## Initiating (Phase 3)

- `project-charter.md`
- `business-case.md`
- `stakeholder-register.md`
- `assumption-constraint-log.md`
