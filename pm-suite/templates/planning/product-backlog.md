## Definition of Ready

An item is **Ready** when it has:
- A clear user / outcome
- Acceptance criteria
- Estimated size (or fits within team's ready-size threshold)
- A linked benefit in `business-case.md`
- No unresolved blocking dependencies

## Definition of Done

(Mirrors `quality-plan.md`.) An item is **Done** when it has:
- Acceptance criteria verified
- Quality checks per quality plan
- Documentation updated as required
- Demonstrable / deployable per the project's release approach
