## Quality objectives

## Definition of Done (project-wide)

A deliverable is **Done** when:
- Acceptance criteria (per item) are verified.
- Required reviews have happened (peer, security, accessibility, compliance, etc., per type).
- Documentation is updated.
- Tests / evidence are recorded.
- Approval is recorded by the named acceptor.

## Acceptance criteria pattern

Use Given / When / Then or equivalent. Each item has criteria **before** work starts.
