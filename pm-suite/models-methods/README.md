# Models, Methods, Artifacts

Lands in Phase 3+. This directory will hold the reusable knowledge that agents draw on but that is not an artifact in itself.

## Planned contents

**Models** (how we think):
- Cynefin (complexity)
- Tuckman (team formation)
- Kotter / ADKAR (change management)
- Stacey matrix (uncertainty × agreement)
- Power / interest grid (stakeholders)

**Methods** (how we work):
- Estimation: three-point, planning poker, reference class forecasting
- Prioritization: MoSCoW, WSJF, RICE, Kano
- Risk: qualitative scoring, Monte Carlo, decision-tree analysis
- Measurement: EVM, velocity, cycle time, lead time, DORA

**Heuristics**:
- When to escalate vs. delegate
- When to prefer predictive vs. adaptive elements
- When to call complexity vs. complication
